Constraints:
- `0 <= n <= 2^31 - 2`
- `n` is even.

Original rustgym code (never modified):

```rust
fn reverse_bits(x: u32) -> u32 {
        let mut res = 0;
        for i in 0..32 {
            let bit = x & 1 << i;
            let travel = (31 - i as i32) - i as i32;
            if travel > 0 {
                res |= bit << travel;
            } else {
                res |= bit >> -travel;
            }
        }
        res
    }
```
